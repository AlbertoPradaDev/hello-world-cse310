# hello-world-cse310

# Overview

As a software engineer, I want to strengthen my foundation in TypeScript and practice a clean workflow for building, documenting, and publishing software with Git and GitHub.

This software is a simple command-line program written in TypeScript. It prints "Hello World" and then shows a personalized greeting that changes depending on the time of day. The user can pass their name as an argument when running the program.

My purpose for creating this software was to set up a working TypeScript development environment, understand how the TypeScript compiler turns .ts files into JavaScript, and practice using static types in a small project.

[Software Demo Video](https://www.youtube.com/watch?v=VUEZ2dx-PUs)

# Development Environment

I used Visual Studio Code as my editor, Node.js to run the program, npm to manage dependencies, and Git and GitHub for version control.

The program is written in TypeScript and compiled to JavaScript with the TypeScript compiler (tsc).
